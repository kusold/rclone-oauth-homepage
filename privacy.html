OAuth 2.0 client

Privacy Policy

Last updated: September 30, 2026
Applies to the personal Google Drive OAuth client used with rclone whose home page is this site.

01About this app

This is the privacy policy for a personal OAuth 2.0 client — a client ID and secret issued by Google to a single individual, Mike Kusold, for use with rclone, an open-source command-line file sync tool. The "app" is not a business and operates no infrastructure of any kind. Its entire purpose is letting rclone, running locally, access the Drive account that authorized it.

02What the app can access

When a Google account authorizes this client, Google may grant it these scopes:

  • https://www.googleapis.com/auth/drive — see, edit, create, and permanently delete all of your Google Drive files
  • https://www.googleapis.com/auth/docs — see, edit, create, and permanently delete your Google Docs files
  • https://www.googleapis.com/auth/drive.metadata.readonly — see information about your Google Drive files

Any access under these scopes is performed by the rclone program running on the machine of the person who authorized it, only when they run a command that asks for it. The client ID itself contains no code and runs nowhere.

03Where your data goes

File data moves only between the computer running rclone and Google's Drive API, over an encrypted connection. This app has no servers, no backend, no website logic, and no databases. It cannot receive, inspect, store, process, or transmit your data, because there is nothing on its side to receive it.

04What is collected

Nothing. This site and this client use no analytics, no cookies, no logs, no trackers, and no advertising. The only records of an authorization that exist anywhere are Google's own records and the local rclone configuration on the machine that granted it.

05OAuth tokens on your machine

After authorization, Google issues OAuth tokens, and rclone stores them in its local configuration file (for example ~/.config/rclone/rclone.conf on Linux and macOS). Anyone with access to that file can reach the associated Drive account, so it should be protected like a password.

06Third parties

  • Google processes Drive data under its own Privacy Policy and Terms of Service.
  • rclone is open source — you can read exactly what it does with your data at github.com/rclone/rclone.

07Revoking access

You can revoke this client at any time: Google Account → Data & privacy → Third-party apps with account access → remove the app. Deleting the remote from rclone's configuration also discards its local token.

08Children

This client is not directed to children under 13, and no data is knowingly collected from anyone.

09Changes to this policy

If this policy ever changes, the current version will be posted at this URL with a new "last updated" date.
