OAuth 2.0 client home page

A personal Google Drive client for rclone.

This is the home page of a personal OAuth client — an ID issued by Google to one person so that rclone, the open-source command-line file sync tool, can talk to their own Google Drive. It is not a service, a company, or a product. There is no server, and nothing is collected.

rclone — drive setup
$ rclone config

✓ Token saved to ~/.config/rclone/rclone.conf
$ rclone ls gdrive:

What this app does

  • Lets rclone, running on the authorizing user's own machine, read and write files in their own Google Drive.
  • Requests the three Drive scopes listed below — nothing more.
  • Keeps its OAuth token in rclone's local config file.

What it doesn't do

  • Operate any server, backend, or database — it is just a client ID.
  • Collect analytics, set cookies, or keep logs.
  • See, store, or forward anyone's data. Privacy policy →

Requested scopes

https://www.googleapis.com/auth/drive

See, edit, create, and permanently delete all of your Google Drive files — required for rclone's sync and copy commands.

https://www.googleapis.com/auth/docs

See, edit, create, and permanently delete your Google Docs files, so rclone can handle Docs like any other file.

https://www.googleapis.com/auth/drive.metadata.readonly

See information about your Google Drive files — names, sizes, and modification times, without file contents.

Why does Google call this app “unverified”? It's personal — far fewer than 100 users — so it will never go through Google's verification process. On first sign-in, Google may show an unverified app screen; that's this client. If you reached that screen unexpectedly, an rclone config somewhere is pointing at the wrong client ID.
